# scripts-ros

Модульный установщик для RouterOS. Вместо одного монолита на 30 КБ — маленький
загрузчик, общая библиотека и набор модулей, которые качаются по одному и
выполняются из оперативки.

Меню показывает, что уже настроено на этом роутере, и позволяет доустановить
только недостающее. Всё идемпотентно: повторный запуск ничего не ломает и
честно пишет `[ == ]` там, где менять нечего.

```
==============================================
 1  [ ok ] Base settings       dns 8 fwd, ntp synced, ipv6 off
 2  [ ok ] Container storage   tmp1 tmpfs, 476 MiB free, repull ok
 3  [ ~~ ] MihomoProxyRoS      STOPPED, 138 envs
 4  [ -- ] DNSProxy            not installed
 5  [upd ] Resource lists      4 of 4 installed, 1 UPDATE
 6  [ ok ] Proxy link / sub    LINK1 vless://ba..., SUB set

  a  [    ] install everything (1..6)
  s  [    ] full status report
  x  [    ] uninstall
  q  [    ] quit
==============================================
```

## Требования

* **RouterOS 7.24.1 или новее.** Ниже установщик откажется работать.
  7.24.0 отсекается отдельно: в ней сломан поиск аргументов в консольной
  команде `find`, а весь проект построен на `find where comment=`.
* Включённый режим контейнеров — нужен только для пунктов 2, 3 и 4:

```
/system/device-mode/print
/system/device-mode/update mode=advanced container=yes traffic-gen=yes
```

На подтверждение даётся около 5 минут: выключите и включите питание либо
кратковременно нажмите любую физическую кнопку на устройстве.

## Запуск

Вставьте в терминал RouterOS:

```routeros
:global r [/tool fetch url="https://raw.githubusercontent.com/Medium1992/scripts-ros/refs/heads/main/install.rsc" mode=https output=user as-value]
:global s [:parse ($r->"data")]
$s
```

Загрузчик сам проверит версию, подтянет библиотеку и покажет меню. Выбор —
цифрой.

## Из чего состоит

| файл | назначение |
|---|---|
| `install.rsc` | единственное, что вставляется руками: preflight, меню, запуск модулей |
| `lib.rsc` | общие функции: вывод, идемпотентность, ввод, fetch, md5, состояние |
| `status.rsc` | живые проверки состояния для строк меню |
| `manifest.rsc` | md5 всех обновляемых файлов, генерируется `tools/gen_manifest.py` |
| `modules/` | сами модули |
| `lists/` | движок обновления списков и наборы ресурсов |
| `assets/` | скрипты, которые ставятся на роутер как есть |

## Списки ресурсов: движок отдельно, данные отдельно

Скрипты `FWD_update`, `FWD_update_RU` и `IP_MihomoProxyRoS` — это один и тот же
движок (`lists/engine.rsc`) плюс ваш персональный список ресурсов
(`FWD_update_list` и такие же). Движок обновляется из репозитория, **ваш список
после первой установки не трогается никогда**. Поэтому добавление или удаление
сайтов в вашем списке не конфликтует с обновлением движка.

Если вы всё-таки правите сам движок, работает трёхстороннее сравнение по md5:

| ваша копия | апстрим | что произойдёт |
|---|---|---|
| не менялась | изменился | тихо обновится |
| вы правили | не менялся | останется как есть |
| вы правили | изменился | спросит: оставить / взять новое / пропустить |

Предыдущая версия всегда сохраняется рядом как `<имя>_bak`.

## Локальная разработка

Установщик умеет брать файлы не с GitHub, а с любого HTTP-сервера:

```routeros
:global mBase "http://192.168.88.17:8000"
```

```bash
python -m http.server 8000        # в корне репозитория
```

Ещё есть ветка: `:global mBranch "dev"` до запуска загрузчика.

Для работы с тестовым роутером положите рядом файл `.lab` (он в `.gitignore`):

```
HOST=192.168.88.3
USER=admin
PASS=...
```

```bash
python tools/ros.py cmd   "system resource print"
python tools/ros.py run   probe.rsc
python tools/ros.py check lib.rsc modules/*.rsc   # синтаксис глазами RouterOS
```

`tools/ros.py check` заливает файлы на роутер и просит его собственный парсер
их разобрать, ничего не выполняя. Локальный линтер не знает правил RouterOS,
а роутер знает.

`probe.rsc` проверяет примитивы, на которые опирается библиотека: md5 через
`:convert`, `:retry`, `/file add contents=`, побайтовый `:len`. Запускайте его
после выхода новой версии RouterOS.

## Почему весь вывод на английском

RouterOS не работает с многобайтовыми кодировками в консоли, а `:len` считает
байты, а не символы — из-за этого таблица статусов с кириллицей разъезжается.
Поэтому весь рантайм ASCII, а русский живёт здесь, в документации.

## Ограничения

* `40-dnsproxy` спрашивает имя образа: в `script21.rsc` контейнер DNSProxy
  упоминался, но никогда не создавался, готовой ссылки на образ нет.
* Модули с `/terminal ask` (2, 4, 5, 6 и `14-hardening`) интерактивные —
  из планировщика их запускать нельзя.
* `90-uninstall` не откатывает базовые настройки: DNS, NTP, IPv6 и hardening —
  это обычная конфигурация роутера, а не следы установщика.
