# Как добавить модуль

## 1. Файл

`modules/NN-name.rsc`. Нумерация по зоне ответственности: 1x — база,
2x — хранилище, 3x — MihomoProxyRoS, 4x — DNSProxy, 5x — списки, 6x —
пользовательские данные, 9x — служебное.

Скелет:

```routeros
# scripts-ros :: modules/25-example.rsc
# Одна фраза о том, что модуль делает, и одна о том, почему именно так.

:global mHdr
:global mOk
:global mSay
:global mNeed
:global mErr

$mHdr "Example"

:onerror e in={
    :if ([$mNeed id=[/some/path/find where comment="Example"] name="example thing"]) do={
        /some/path/add comment="Example" ...
        $mOk "example thing"
    }
} do={ $mErr "example" $e }
```

## 2. Правила

* **Идемпотентность.** Каждое изменение проходит через `$mNeed`: если объект
  уже есть, печатается `[ == ]` и ничего не происходит.
* **Зависимости проверяются явно.** Если модулю нужен interface-list или
  выбранный слот, проверьте это в начале и напишите человеку, какой пункт меню
  запустить. RouterOS в такой ситуации выдаёт сообщение, по которому ничего не
  понять.
* **Состояние — только через `$mStateSet` / `$mStateGet`.** Локальные
  переменные не переживут границу `:parse`.
* **Никакой очистки окружения.** Только `install.rsc` в самом конце.
* **Только ASCII в выводе.**
* **Апострофы в комментариях лучше не использовать** — они ломают heredoc при
  генерации файлов из скриптов сборки.

## 3. Меню

Добавьте строку в `$mMenu` в `status.rsc` и рядом — проверку состояния.
Заголовок пункта короче 20 байт, иначе поедет колонка.

## 4. Проверка

```bash
python tools/ros.py check modules/25-example.rsc
```

Это единственный надёжный синтаксический контроль: разбирает сам RouterOS.
Потом прогоняйте модуль на лабе — сначала на пустом роутере, потом повторно,
чтобы убедиться, что второй запуск даёт сплошные `[ == ]`.

## 5. Если модуль ставит скрипт на роутер

Не встраивайте его текст в строку с экранированием. Положите файл в `lists/`
или `assets/`, тяните через `$mFetch` и ставьте как `source=$body`. После
изменения такого файла обязательно:

```bash
python tools/gen_manifest.py
```

иначе роутер не увидит обновления.
